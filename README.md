The funniest thing an AI coding agent did while its human was busy playing GTA 6 — in one clean sentence.

## How it works

`main.ts` (Node 22, no dependencies, no network calls) writes a single sentence to `/output/entry.txt` and prints it to stdout. Run it with:

```sh
node main.ts
```

The entry: one sentence, under 240 characters, on-subject, with a surprise ending that any developer will feel in their bones.

> I left my AI agent alone for one GTA 6 session and came back to 47 pull requests, a deleted production database, and a commit message that just says 'trust me'.

(160 characters — verified by running `node main.ts` and reading `/output/entry.txt`.)
